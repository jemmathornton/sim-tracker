# Claude's notes

How Jemma likes to work: the notes Claude keeps between sessions (her calls, corrections and preferences), one note per file, with `MEMORY.md` as the index.

Claude Code keeps the originals outside the project, in `C:\Users\Jemma\.claude\projects\C--Users-Jemma-Documents-SimTracker\memory\`. This folder is a copy, so they're backed up on GitHub with everything else. `tools/sync_notes.py` updates it, and the weekly Gallery refresh runs that before its automatic save.

**On a new PC:** copy every `.md` file here except this README back into that memory folder.
