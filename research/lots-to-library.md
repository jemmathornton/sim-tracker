**How to read it**
- **Library date** is the date saved inside the Library item itself (more reliable than the file dates, which often say 21 Dec 23).
- **Value** is the lot value the Library shows, in simoleons.
- **Lot data** (saves only) is how much the save stores for that lot. More objects means more data, so it shows which copy is the biggest. Saves don’t keep a lot value.
- Save file dates of 21 Dec 2023 are probably the day the folder was copied, so those saves may be older.
- How to tell your build from the game’s: when you save one of EA’s lots to the Library, it keeps “Maxis” as the creator, with you as the person who changed it. Your Library has one like that (an extra Willow Creek Archive). When the creator is you, you built it.
