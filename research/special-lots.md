# The "special lots": which you can build and share (6 Nov)

Your plan has 21 lots I'd been calling "special" and leaving out of the build lists. Read 6 Nov from the game's own settings for each lot type (patch 1.129), they fall into three groups:
- ordinary lot types, built and shared like any other;
- special types the game can still upload, as a different type;
- special types it gives no upload type at all.

Report only. The game files don't say whether every one of them can be edited, so treat the upload groups as "the game expects these could be shared", and try in game.

## Ordinary lot types: build and share as normal

I was wrong to leave these out of the build lists:
- **Alam Museum of Archaeology** (Selvadorada, 64×64): a plain **Museum**. Museums do best on your Gallery (research/build-order.md).
- **Granite Falls Forest** (Granite Falls), **Belomisia Trailhead** (Selvadorada), **Isle of Volpe** (Henford-on-Bagley): **National Parks**, an ordinary type. It needs a grill, a picnic table and a bin (research/playtest-checklist.md).

## Special types that the game uploads as another type

These lot types are hidden from the lot-type menu, but the game gives each a type to upload as. So a renovated copy can go on the Gallery; it just shows there as Generic or Residential:
- **Uploads as Generic:**
  - Ancient Ruins (Windenburg);
  - Von-Haunt Estate (Chalet Gardens, Windenburg);
  - The Bluffs (Island Bluff, Windenburg);
  - Hermit's House (Granite Falls);
  - Plumbob Pictures (Acting Studio, Del Sol Valley);
  - Netherworld Department (Ravenwood).
  - The Magic Realm is the same kind, and you've already shared it.
- **Uploads as Residential:** Police Station, FutureSim Labs and Willow Creek Hospital (Magnolia Promenade), and Sixam. These are the career and alien lots.
- **Watch out:** when you place one of these from the Gallery, it comes in as Generic or Residential. The lot then has to be set back to its special type, which may only be possible with a cheat. Not checked in game.
