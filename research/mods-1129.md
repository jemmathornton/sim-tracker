EA’s patch 1.129 (PC 1.129.39.1030, 27 Oct 2026) is already installed on your PC (the game’s `Default.ini`, 28 Oct). I only read your Mods folder and changed nothing in it. Version checks were done on copies in a temporary folder. Nothing in the project changed apart from this note.

How to read the status column:

- **Fine:** the creator, or a tracker quoting the creator, says it works with 1.129.
- **Unknown:** nobody has said anything about 1.129 yet. This is not the same as broken.
- **Out of date in the files:** the mod replaces one of EA’s own game files with its own copy, and EA has changed that file since the mod was made. I compared each of these copies with the game’s 1.129 version of the same file. While the mod is installed, EA’s newer changes to that file are lost. This comes from reading the files, not from testing in the game.

About the sources: EA’s forum list ([Broken and Updated Sims 4 Mods and CC: patch 1.129](https://forums.ea.com/discussions/the-sims-4-mods-and-custom-content-en/broken-and-updated-sims-4-mods-and-cc-patch-1-129-oct-27-2026/13830311)) blocks automatic reading, so anything quoted from it comes from search-engine summaries. ## Part 2: premade fix mods for the new save

### What EA changed in 2026 (this decides what any premade mod can do)

- **Since the 3 Feb 2026 update (1.121), the game works out siblings, cousins and in-laws from parents itself.** EA’s notes for modders, as summarised by a search engine, say:
  - code can no longer set family relations other than direct parent and partner links;
  - indirect relations can’t be set by code or tuning;
  - family relationship bits without a matching family-tree link get archived or removed ([EA modder notes](https://forums.ea.com/blog/the-sims-game-info-hub-en/the-sims-4-code-changes-for-modders---feb-3rd-base-game-update/13120743)).

  So a mod (or MCCC) can only join siblings or cousins through parents, the way your site’s “Unknown” parents do. That MCCC is limited the same way is my reading of those notes (unconfirmed).
- **EA’s premade ancestors only come in new saves.** Only the Goths, Landgraabs, Thebes, Capps and Montys, and Darongs got them ([Family tree Q&A](https://simscommunity.info/2026/02/03/sims-4-family-tree-q-and-a/), [TheSimsTree](https://thesimstree.com/en/news-about-the-sims/tst-news/the-sims-4-family-tree-overhaul-developer-qanda-breakdown.html)).
- **EA’s own starting-relationship list is unchanged by 1.129:** 348 starting relationships and 81 family fix-ups. This is from the project’s re-read after the patch (commit 8516e5e). The list already joins some siblings and cousins through unseen parents, e.g. Lilith and Caleb Vatore, who share a grandparent with Lily Zhu, and also the Groves, the Gomes sisters, the Kunals, and Lilliana Kealoha with Duane Talla.
